\chapter{Objetivos}
\label{cha:objetivos}

En esta sección se detallan los objetivos tanto generales como específicos planteados para el desarrollo del informe.

\section{Objetivo General}
\label{sec:objetivo_general}
Identificar sugerencias de usuarios dentro de un dataset de reseñas turísticas provenientes de la plataforma de TripAdvisor.

\section{Objetivos Específicos}
\label{sec:objetivos_especificos}

\begin{itemize}

    %\item Investigar sobre diferencias entre distintos modelos de Inteligencia Artificial

    \item Implementar un modelo transformer preentrenado para el etiquetado de datos 

    \item Entrenar un modelo transformer para que sea capaz de etiquetar diferenciando entre feedback y sugerencias

    \item Validar que el modelo Transformer capaz de etiquetar feedback como sugerencias correctamente

    \item Ejecutar el modelo Transformer sobre el dataset de reseñas turísticas

    \item Evaluar la precisión del modelo (OPCIONAL)

\end{itemize}
