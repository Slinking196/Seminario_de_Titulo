\chapter{Descripción del Conjunto de Datos}
\label{cha:Descripción del Conjunto de Datos}

En esta sección, veremos una explicación detallada de los datos que utilizaremos como material de investigación, procedencia, trabajo de preprocesamiento que realizaremos, limpieza de los datos y preparación para un posterior análisis y uso de modelos transformers para el etiquetado de datos, dando enfasis en que esta sección en particular corresponde a un paso fundamental dentro de la metodología que definimos, además de permitirnos filtrar la información que nos será verdaderamente relevante para este trabajo y de esta forma buscamos reducir la carga de los modelos Transformers a la hora del etiquetado de datos.

\section{\textbf{Conjunto de Datos (Dataset)}}
Para este trabajo utilizaremos un dataset que contiene comentarios dirigidos directamente a los servicios turísticos de Chile utilizados por usuarios de la plataforma de TripAdvisor. La estructura se compone de 14 columnas que se pueden visualizar en la tabla \ref{tab:variables_tripadvisor}.

A partir de todas estas columnas hemos considerado quedarnos con 3 de ellas, debido al valor que estas significan tanto para el trabajo de los modelos Transformers como para el análisis posterior de datos que deberemos realizar en etapas posteriores.

A continuación detallaremos las columnas de interés para nuestro trabajo, que significan y las razones que nos llevan a considerarlas como relevantes para nuestro análisis.

\begin{enumerate}
    \item \textbf{title:} Título del comentario creado por el usuario, que puede contener información relevante para la detección de sugerencias, ya que es común que los usuarios utilicen el título para destacar aspectos específicos de su experiencia, lo que puede incluir sugerencias o recomendaciones relacionadas con el servicio turístico.
    \item \textbf{review text:} Comentario del usuario respecto a su experiencia como turista en determinado servicio de trasfondo turístico (Dato que naturalmente servirá como base para analizar con modelos Transformers y determinar si es que existe una intencionalidad de sugerencia en este).
    \item \textbf{language:} Idioma del comentario, que puede ser español, inglés, portugués, aunque como se mencionó anteriormente, existen comentarios con mezcla de idiomas, por lo que se hace necesario un trabajo de reconocimiento de lenguaje mas elaborado para determinar el idioma predominante de cada comentario. Además de esto, el lenguaje detectado por tripadvisor depende de la configuración del usuario, por lo que es posible que existan comentarios en español con idioma detectado como inglés, o viceversa, lo que hace necesario un trabajo de reconocimiento de lenguaje mas elaborado para determinar el idioma predominante de cada comentario.
\end{enumerate}

\section{\textbf{Librerías}}
\label{cha:OLLAMA}
\label{cha:MLX}

Para el trabajo de Comprensión de Lenguaje Natural, reconocimiento de idiomas e análisis de datos, utilizaremos diversas librerías del lenguaje Python que nos permitirán llevar a cabo nuestros objetivos, como lo son el identificar el contenido que posee cada columna de nuestro conjunto de datos, reconocer el idioma predominante en cada comentario, hacer limpieza de datos repetidos, eliminación de filas con datos nulos, hasta el uso de modelos Transformers para el etiquetado de datos, entre otras tareas que se irán detallando a lo largo del desarrollo de esta investigación. Las librerías más relevantesque utilizaremos son las siguientes:

\begin{itemize}
    \item \textbf{pandas:} Librería que proporciona estructuras de datos y herramientas de análisis de datos, que nos permitirá manipular y analizar los datos de nuestro conjunto de datos de manera eficiente.
    \item \textbf{langdetect:} Librería que se utiliza para detectar el idioma de un texto, lo que nos permitirá identificar el idioma predominante en cada comentario de nuestro conjunto de datos.
    \item \textbf{lingua-py:} Librería de detección de idiomas que utiliza un enfoque basado en n-gramas para identificar el idioma de un texto, lo que nos permitirá complementar la detección de idiomas realizada por langdetect y mejorar la precisión en la identificación del idioma predominante en palabras individuales de cada comentario de nuestro conjunto de datos.
    \item \textbf{re:} Librería de expresiones regulares que nos permitirá realizar tareas de limpieza de datos, como eliminar caracteres no deseados, normalizar el texto, entre otras tareas de preprocesamiento.
    \item \textbf{collections:} Librería que proporciona contenedores de datos especializados, como diccionarios ordenados, que nos permitirá organizar y contar la frecuencia de palabras o frases en nuestros comentarios, lo que puede ser útil para el análisis de datos y la detección de sugerencias.
    \item \textbf{mlx\_lm:} Librería que hace uso del framework MLX que proporciona modelos de lenguaje preentrenados configurados especialmente para ser ejecutados en dispositivos Apple Silicon, que nos permitirá utilizar modelos Transformers para el etiquetado de datos y la detección de sugerencias en los comentarios de nuestro conjunto de datos.
    \item \textbf{nltk:} Librería de procesamiento de lenguaje natural que nos permitirá realizar tareas de tokenización, lematización, eliminación de stop words, entre otras tareas de preprocesamiento de texto que serán necesarias para preparar nuestros datos para el entrenamiento y etiquetado de los modelos Transformers a utilizar.
    \item \textbf{simplemma:} Librería de lematización que nos permitirá reducir las palabras a su forma base o raíz, lo que puede ser útil para mejorar la precisión de los modelos Transformers al trabajar con texto en diferentes formas gramaticales.
    \item \textbf{ollama:} Librería que nos permitirá interactuar con la API del framework Ollama que proporciona modelos de lenguaje preentrenados alojados en local, lo que nos facilitará el proceso de etiquetado de datos y la detección de sugerencias en los comentarios de nuestro conjunto de datos.
\end{itemize}

\section{\textbf{Objetivo del conjunto:}}

Debido a que el objetivo de la investigación se basa en la detección de sugerencias, el dataset de comentarios de TripAdvisor resulta particularmente útil, definir las herramientas para trabajar y analizar preeviamente los datos con los que disponemos nos permitirán desarrollar un trabajo mas especializado y que potencialmente nos podrá llevar a mejores resultados en lo que es nuestro objetivo principal de la detección de sugerencias.
